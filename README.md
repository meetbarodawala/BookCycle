# 📚 BookCycle — Android Bookstore Application

**BookCycle** is an Android-based digital bookstore application designed to make discovering, browsing, and purchasing books easier and more convenient.

The application brings essential bookstore functionalities into one mobile platform, including book discovery, category-based browsing, shopping cart management, order processing, and chatbot assistance.

## 🎯 Project Objectives

- Simplify access to books through a mobile application.
- Provide efficient book searching and category-based navigation.
- Improve user interaction through chatbot assistance.
- Simplify shopping with cart and order management.
- Provide a user-friendly and organised digital bookstore experience.

## ✨ Key Features

- **User Authentication:** Account registration, login, and user validation.
- **Book Browsing:** Explore available books through the application.
- **Category Management:** Discover books organised by categories.
- **Search Functionality:** Find books using relevant search criteria.
- **Book Details:** View information about individual books.
- **Shopping Cart:** Add, remove, and manage selected books.
- **Order Management:** Process purchases and view order history.
- **Payment Processing:** Payment functionality described in the project design.
- **AI Chatbot:** Interactive assistance and book-related recommendations.
- **User Profile:** View and manage personal profile information.
- **Notifications:** Support for application updates and user communication.

## 🔄 Application Workflow

1. A user registers or logs into the application.
2. The user explores available books.
3. Books can be discovered using search and categories.
4. The user views book details and adds selected books to the cart.
5. The user proceeds through the order and payment workflow.
6. Order information can be accessed through order history.
7. Chatbot assistance provides an additional way to interact with the application.

## 🧪 Software Testing

The project report describes the following testing approaches:

- **Unit Testing:** Testing individual components such as login validation and cart operations.
- **Integration Testing:** Checking communication between modules.
- **System Testing:** Evaluating the complete application workflow.
- **User Acceptance Testing:** Assessing usability and whether the application meets user expectations.
